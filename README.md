# Algorithms and Proofs

A collection of competitive programming solutions developed with an emphasis on algorithmic reasoning, mathematical intuition, and rigorous correctness proofs.

## Objectives

- Develop a deeper understanding of algorithms and data structures.
- Document the observations and ideas that lead to a solution.
- Establish correctness through formal or informal mathematical proofs.
- Analyse time and space complexity.
- Maintain a structured, reusable record of problem-solving techniques.

## Repository Structure

Each problem is documented using two files:

- **Implementation (`.cpp`)** — the C++ solution.
- **Analysis (`.md`)** — intuition, key observations, algorithm, correctness proof, complexity analysis, and implementation notes.

Problems are organised primarily by difficulty rating.

## Problem Analysis Format

Each written analysis aims to cover:

1. **Problem statement** — a link to the original problem.
2. **Intuition** — the central idea behind the solution.
3. **Observations** — the properties that make the approach possible.
4. **Algorithm** — a precise description of the method.
5. **Correctness proof** — an argument establishing why the algorithm works.
6. **Complexity analysis** — time and auxiliary space complexity.
7. **Implementation notes** — edge cases and important details.

## Language

- C++

## Philosophy

The goal is not merely to obtain accepted submissions, but to understand why an algorithm works, when it applies, and how its correctness can be justified.
